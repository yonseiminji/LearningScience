BCcampus Introduction to Sociology (3rd Canadian ed., 2023), Chapter 5 — 차곡차곡 튜터용 자료

- bccampus_socialization_ch05_en.js: 업로드 원문 영문 전체 추출, sourceLine 정렬
- bccampus_socialization_ch05_ko.js: 영문 원문+한국어 번역을 1:1로 정렬, 학술 용어 영문/한국어 동의어 병기
- bccampus_socialization_ch05_translation_audit.md: 누락 및 번역검토 보고서
- bccampus_socialization_ch05_review_candidates.csv: 검토 문장의 영어·한국어 원문 전체 포함

서식: ES module; import { socializationEN } from './bccampus_socialization_ch05_en.js';
      import { socializationKO } from './bccampus_socialization_ch05_ko.js';

인쇄 PDF 쪽수: 현재 업로드된 TXT에는 페이지 경계가 없어 미검증.
절별 pageTransition과 line 1-based sourceLine을 제공.
페이지 라벨 '원전: pp. ...'를 추측으로 넣지 않았음.
