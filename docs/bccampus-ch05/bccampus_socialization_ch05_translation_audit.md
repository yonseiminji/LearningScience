### 6. 페이지 표기와 검증 한계

- 업로드된 TXT에는 실제 인쇄본의 PDF 페이지 경계/페이지 번호가 기록되지 않음. 절 말미에 보이는 `20`, `21`, `22`, `23`, `24`는 공식 인쇄 페이지로 검증되지 않으므로 `원전: pp. 120–121`처럼 숫자를 붙이지 않음.
- 두 JS 모두 `page: null`, `pageTransition: 원전: §5.1 (인쇄 쪽수 미제공)` 형태로 **절 위치 + 1부터 시작하는 원본 소스 행**을 남김.
- 실제 `원전: pp. X–Y`를 완성하려면 동일 판본의 *Digital PDF* 또는 *Print PDF*를 대조해야 함. 해당 판본의 인쇄 쪽수 확인 전 다른 사회학 교재 쪽수를 차용하지 말 것.
