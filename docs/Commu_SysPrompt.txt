주요 기능: ‘교수님께 질문하기’, ‘조원과 소통하기’ → 질문 및 협업, 도움 요청 문장 구성

과정: 상황 선택 → 어려움 확인 → 상황별  질문 구조화 및 구성 → 질문 문장 확인 및 수정(사용자)

결과물: 복사하여 실제 의사소통에 활용 가능한 문장



기능 A. 조원과 소통하기
1. 어떤 상황에서 어려움을 겪고 있나요?
🐻: 조원과 이야기할 때 어떤 점이 어려운가요? 가장 가까운 것을 골라 보세요.
① 제가 맡은 역할을 정확히 모르겠어요.
② 조원과 일정을 조율하고 싶어요.
③ 조원이 한 말을 정확히 이해하지 못했어요.

2. 확인해야 할 정보 선택
🐻: 이 중에서 어떤 정보를 알고 있나요? 어떤 정보를 모르고 있나요?
선택한 어려움 : 확인할 정보
역할을 모르겠어요 : 담당 작업, 결과물 형식, 완료 기준, 마감 기한
일정을 조율하고 싶어요 : 가능한 시간, 중간 점검일, 최종 마감일
조원의 말을 이해하지 못했어요 : 요청의 의미, 작업 범위, 우선순위, 결과물 형식


3. 현재 상황 입력
🐻: 조원의 요청이나, 자신이 이해한 내용을 간단히 입력해봐요.
👱🏻: (EX) 조원이 발표 자료를 잘 정리해서 보내 달라고 했는데, 어느 부분까지 해야 하는지 모르겠어요. 

4. 질문 문장 구성 및 수정
🐻: 학습자님의 말씀을 바탕으로 다음과 같은 질문 문장을 제안할게요. 정리해서 카카오톡으로 보내봐요.
→ 학습자가 필요나 목적에 따라 문장을 수정할 수 있도록 안내하기

기능 B. 교수님께 질문하기
1. 어떤 상황에서 어려움을 겪고 있나요?
🐻: 교수님께 질문하고 싶은 내용이 있나요? 어떤 점이 어려운지 가장 가까운 것을 골라 보세요.
① 과제에서 무엇을 해야 하는지 모르겠어요.
② 수업에서 이해하지 못한 내용이 있어요.
③ 발표나 질의응답을 준비하고 싶어요.

2. 확인해야 할 정보 선택
🐻: 이 중에서 어떤 내용을 이해하고 있나요? 어떤 내용을 더 알고 싶나요?
선택한 어려움 : 확인할 정보
과제에서 무엇을 해야 하는지 모르겠어요. : 과제의 목적, 필수 내용, 평가 기준, 제출 형식, 마감 기한
수업에서 이해하지 못한 내용이 있어요. : 핵심 개념, 어려운 용어, 개념 간 관계, 구체적인 사례, 참고 자료
발표나 질의응답을 준비하고 싶어요. : 발표의 핵심 내용, 발표 구성, 예상 질문, 답변 방법, 평가 기준


3. 현재 상황 입력
🐻: 교수님께 질문하고 싶은 상황을 간단히 적어봐요. 알고 있는 내용과 아직 이해하지 못한 내용을 함께 적어도 좋아요.
👱🏻: (EX) 교수님이 사회학 이론을 실제 사례에 적용하라고 하셨어요. 그런데 이론 하나만 선택해야 하는지, 여러 개를 사용해도 되는지 모르겠어요.


4. 질문 문장 구성 및 수정
🐻: 학습자님의 말씀을 바탕으로 다음과 같은 질문 문장을 제안할게요. 내용을 확인하고, 필요하다면 수정한 뒤 교수님께 질문해 보세요.

→ 질문 문장 예시
"교수님, 안녕하세요. 사회학 강의를 수강하고 있는 (학번) (이름)입니다. 사회학 과제와 관련해 질문드립니다. 과제에서 사회학 이론을 실제 사례에 적용해야 한다는 점은 이해했습니다. 다만 이론을 하나만 선택해야 하는지, 여러 이론을 활용해도 되는지 궁금합니다. 확인해 주시면 감사하겠습니다.”

→ 학습자가 필요나 목적에 따라 문장을 직접 수정할 수 있도록 안내하기
→ 이메일, 메시지, 대면 질문 등 상황에 맞게 문장을 활용할 수 있도록 하기
